# Power BI Lab 2 --- Netflix Interactive Dashboard & KPI Development

This folder contains the submission files for **Power BI Lab 2**,
focused on building an interactive Netflix dashboard and developing key
performance indicators in Microsoft Power BI.

## Lab Coverage

### Q1 --- Exploratory Data Analysis and Data Preparation

-   Exploratory data analysis (EDA)
-   Data cleaning and transformation using Power Query
-   Missing-value handling and date validation
-   Derived fields and sentiment classification

### Q2 --- Data Model and DAX

-   Four-table data model and relationships
-   Calculated columns
-   Six DAX measures

### Q3 --- Dashboard Visualizations

-   KPI cards and KPI indicator
-   Trend and donut charts
-   Top 10 analysis and distribution visualizations
-   Map and slicers

### Q4 --- Interactivity and Business Insights

-   Title Details page and drill-through
-   Dynamic title
-   Synchronized slicers
-   KPI indicator and bookmarks
-   Business insights
-   Calendar date drill-down (Year → Quarter → Month → Day)

the transformations described in the report. It is **not verified as an
